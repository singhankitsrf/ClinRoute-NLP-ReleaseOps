Leakage-aware protocol

Identifiers are redacted and identical normalized notes are removed before the deterministic 80/20 split. Saved hashes and predictions make the benchmark auditable.

Evidence boundary

Perfect synthetic classification is expected here because the generator uses shared template vocabulary and states urgency explicitly. These measurements demonstrate pipeline reproducibility, not clinical generalization.

Portable inference

Versioned TF-IDF vocabulary, IDF weights and logistic-regression coefficients are exported from the trained scikit-learn pipeline and executed client-side.

Release gate

GitHub Actions regenerates the seeded benchmark, runs the model-regression gate, validates browser/Python parity, then publishes the exact validated static bundle.

Responsible boundary

Confidence thresholds are engineering examples. Identifier redaction is best-effort. The system explicitly avoids diagnosis or clinical-performance claims.
